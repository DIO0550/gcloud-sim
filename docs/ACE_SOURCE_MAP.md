# 添付48資料の学習目標から演習への対応表

添付ZIP内の全48資料を対応付けた台帳。本文や図は転載せず、独自の設定演習・判断演習へ案内する。導入、復習、リンク集は、その範囲の代表演習を示す。CLI欄はコマンドの入口であり、実行例と達成条件はミッションの手順を確認する。

ミッションIDはアプリの分類→ミッションから選ぶための識別子。全IDが存在することをテストで検証する。対応とは限定教材で学習目標を扱うことで、全製品・全API・本番性能の完全再現ではない。各分野の再現範囲をリンク先に記載する。Console/mobile/Marketplaceの操作、AI推論、実Cloud Shell、実料金/可用性/性能は判断教材であり実操作は行わない。
